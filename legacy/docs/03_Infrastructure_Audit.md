# Document 03: Infrastructure Audit

## 1. Service Inventory & Resource Allocation
The following table details the configured services, their underlying images, and resource limits as defined in the `docker-compose.yml` configuration.

| Service | Image / Build Context | Memory Limit | Network Aliases |
| :--- | :--- | :--- | :--- |
| **opensearch** | `opensearchproject/opensearch:latest` | 2 GB | `opensearch` |
| **redis** | `redis:7-alpine` | 128 MB | `redis` |
| **api-ts** | `./api-ts` (Bun) | 1 GB | `api-ts` |
| **frontend-next** | `./frontend-next` (Next.js) | 2 GB | `frontend-next` |
| **fetcher** | `./fetcher` (Bun) | 1 GB | `fetcher` |
| **caddy** | `caddy:2-alpine` | Unset | `caddy` |

**Total Configured Memory Reservation:** ~6.1 GB

## 2. Network Configuration
*   **Network Name:** `device_inventory`
*   **Driver:** `bridge`
*   **Isolation:** All services communicate within this private network. Only Caddy exposes ports to the host interface.

## 3. Persistent Storage
The system utilizes named Docker volumes to maintain state persistence independent of container lifecycles.

| Volume Name | Mount Path | Content Description |
| :--- | :--- | :--- |
| `opensearch_data` | `/usr/share/opensearch/data` | OpenSearch indices and cluster state. |
| `redis_data` | `/data` | Redis Append Only File (AOF) and snapshots. |
| `fetcher_data` | `/data` | JSON data snapshots and delta query tokens. |
| `certs_data` | `/app/.certs` | Shared volume for PFX certificates generated by `api-ts`. |
| `caddy_data` | `/data` | Caddy TLS certificates and configuration state. |
| `caddy_config` | `/config` | Caddy persistent configuration. |
